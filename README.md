## 📌 Project Overview
This project involves web scraping travel package data and performing Exploratory Data Analysis (EDA) to uncover insights related to pricing, destinations, and customer preferences.

## 🔧 Tools & Technologies
- Python
- BeautifulSoup
- Requests
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Project Workflow
- Collected travel data (destinations, price, duration, discounts)
- Cleaned and preprocessed dataset
- Performed EDA to identify trends and patterns
- Visualized insights using graphs

## 📈 Key Insights
- Identified popular travel destinations
- Analyzed pricing trends
- Observed impact of discounts on packages

## ▶️ How to Run
1. Clone the repository  
2. Install libraries:  
   pip install pandas numpy matplotlib seaborn beautifulsoup4 requests  
3. Run the Jupyter Notebook
